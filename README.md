# 📁 File System Simulation (Tree Structure)

This project simulates a file system using a tree data structure.

---

## 🚀 Features

✔ Directory & file management  
✔ Add / delete files and folders  
✔ Search by name or extension  
✔ Display file paths  
✔ Size calculation  
✔ Access control (USER / SYSTEM)  

---

## 📁 Files

- Project2.java  
- myfiles.txt  

---

## ▶️ How to Run

1. Run Project2.java  
2. Use menu options to manage file system  

---

## 🎮 Menu

1 - List contents  
2 - Add directory  
3 - Add file  
4 - Delete directory  
5 - Delete file  
6 - Search by name  
7 - Search by extension  
8 - Display path  
9 - Exit  

---

## 🎯 System Logic

- File system is built from a text file  
- Tree structure represents directories  
- Each directory contains:
  - Files  
  - Subdirectories  
- SYSTEM files cannot be deleted  

---

## 🧠 Concepts Used

- Tree Data Structure  
- Recursion  
- File parsing  
- Object-Oriented Programming
